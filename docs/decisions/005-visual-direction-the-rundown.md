# 005: Visual direction: "The Rundown"

**Decision:** The app looks and works like a radio newsroom's show rundown sheet: white paper, black type, thin ruled lines, and red used only as grease-pencil marks (red circle = updated, tick = opened, number = saved). Datasets get permanent codes like `F03` that reporters can cite.

**Why this came up:** Tarik wanted it to look good on a phone and asked for the Impeccable design skill. Tarik ruled out four looks: a government data portal, a generic AI chatbot, a dashboard of charts, and an old-timey almanac. The look had to serve reporters on deadline and stand out in a portfolio.

**Options** (from Impeccable's direction round, which rolls dice so the obvious category look doesn't always win):
1. **The Tuning Dial** (assigned by the roll): radio-receiver controls, a year needle, and signal bars for match quality. Cost: radio styling turns into costume the moment a dial stops doing real work.
2. **The Rundown** (Impeccable's own top pick): the catalog as the day's show rundown. Cost: ruled editorial sheets are a look many designs in this category already land on.
3. **Departure Board / Wayfinding Bands** (challengers): very scannable. Cost: no connection to radio or Milwaukee.
4. **The category standard:** a clean civic-data search app. Cost: indistinguishable from every open-data catalog.

**What we chose and why:** The Rundown (Tarik's choice). Reporters read rundowns every day, so the format needs no explanation, and a rundown row (slug, timing, source) maps directly onto a dataset (name, years, source). Permanent codes replaced the comp's result-position numbers (A1, A2) so a code written in a reporter's notes always points to the same dataset (Tarik's choice, on Claude's recommendation).

**What we gave up:** The Tuning Dial's more distinctive signature. Some risk of looking like other editorial-style apps.

**How we'll know if this was right:** In testing, reporters read a result row correctly (what it is, which years, which source) without explanation, and the built screen passes Impeccable's comparison against the approved comp.
