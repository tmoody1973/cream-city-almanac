# How to Use Ask — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/ask/guide` page that teaches what Ask does, how to read an answer (a live annotated sample), and what a journalist, a nonprofit and a citizen can ask, with example links that open Ask with the question typed in, not sent.

**Architecture:** One example list (`lib/ask/examples.ts`) feeds both the page and the report card. Small pure helpers (`ui/lib/askPrompt.ts`) read and strip `?prompt=`. Ask places the prompt through CopilotKit's own input setter by wrapping its chat view (`chatView` slot), because `CopilotChat` ignores an `inputValue` prop (it passes its own state; verified in `copilotkit-BI7KSQQw.mjs:9036,9597`). The page is a server component like Start here, reusing Start here's layout, Ask's number card and How it works' `PencilNote`.

**Tech Stack:** Next.js 16 App Router, Convex 1.46 (`fetchQuery`), CopilotKit 1.77.2 v2 (`CopilotChatView`, `chatView` slot), Clerk 7.9, Vitest, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-09-ask-guide-design.md` (approved 2026-10-09)

## Global Constraints

- Examples open Ask with the question in the input, focused, **never sent**.
- `prompt` is read once, removed from the address after it's placed, trimmed, capped at 500 characters; empty is ignored.
- Every figure on the page comes from the data (`api.ask.getNumber`); the only typed figure is the unverified-mark example, which says it's made up.
- Every example passes the report card (`npm run ask:card -- --examples`) before the PR opens.
- Colors only from the five tokens; axe clean in light and dark; no sideways scroll on a 390px phone.
- No new dependencies. No changes to Ask's tools, model, or rate limits.
- Commits: conventional, no Co-Authored-By trailer (Tarik's global rule).

## Review Focus

1. A prompt with `&`, `#`, quotes or non-ASCII must arrive intact: covered in Task 2 (unit) and Task 3 (e2e with `&`).
2. On laptops, `/ask?prompt=` redirects to `/?ask=1`: the prompt must survive the redirect and Search's own address writes: Task 3 e2e on desktop.
3. A reload after the question is placed must not re-insert it: Task 3 e2e.
4. Signed out, the question must still be there after signing in: Task 3 e2e.
5. If the live lookup fails or returns a non-`ok` status, the page still renders with the "didn't load" line: Task 4 unit test of `loadSample`.

```ts
// The guide's examples open Ask with a question typed in (?prompt=…), never sent.
export const MAX_PROMPT = 500;

export function readPrompt(search: string): string {
  return (new URLSearchParams(search).get("prompt") ?? "").trim().slice(0, MAX_PROMPT);
}

export const askHref = (question: string) => `/ask?prompt=${encodeURIComponent(question)}`;

// Phones keep /ask; laptops open Ask's column on the home page, so the prompt travels with the redirect.
export function laptopAskHref(search: string): string {
  const prompt = readPrompt(search);
  return prompt ? `/?ask=1&prompt=${encodeURIComponent(prompt)}` : "/?ask=1";
}

// Once placed, the prompt leaves the address, so a reload doesn't put it back.
export function withoutPrompt(href: string): string {
  const url = new URL(href);
  url.searchParams.delete("prompt");
  return `${url.pathname}${url.search}`;
}
```

```tsx
// The guide's examples arrive as ?prompt=…: CopilotChat keeps the input's text in its own state and ignores an
// inputValue prop, so a thin chat view calls its setter once (as if typed), then focuses the box. Never sends.
const PromptFill = createContext<{ prompt: string; placed: () => void }>({ prompt: "", placed: () => {} });
function PrefillChatView(props: CopilotChatViewProps) {
  const { prompt, placed } = useContext(PromptFill);
  const { onInputChange } = props;
  useEffect(() => {
    if (!prompt || !onInputChange) return;
    onInputChange(prompt);
    placed();
    requestAnimationFrame(() => document.querySelector<HTMLTextAreaElement>('section[aria-label="Ask"] textarea')?.focus());
  }, [prompt, onInputChange, placed]);
  return <CopilotChatView {...props} />;
}

const ExamplesLine = () => (
  <p className={styles.examplesLine}><Link href="/ask/guide">What can I ask? See examples →</Link></p>
);
```

```ts
export const SAMPLE_QUESTION = "How many kids under 5 live in poverty in Harambee?";
export const SAMPLE_ARGS = { neighborhood: "Harambee", topic: "Poverty Status by Age", row: "Under 5 years" };

export async function loadSample<T extends { status: string }>(fetch: (args: typeof SAMPLE_ARGS) => Promise<T>): Promise<T | null> {
  try {
    const r = await fetch(SAMPLE_ARGS);
    return r.status === "ok" ? r : null;
  } catch {
    return null;
  }
}
```
