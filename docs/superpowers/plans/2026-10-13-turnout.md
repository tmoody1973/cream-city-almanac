# Election Turnout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ask compares Milwaukee voter turnout across 12 elections, 2016–2022: citywide, one ward across elections, or one election's lowest or highest wards.

**Architecture:**
- **A hand-kept list** (`ELECTIONS`, `convex/lib/turnout.ts`) names each election's catalog family, its file, and its reader:
  - `table`: a queryable file;
  - `sheet`: a workbook's "General Turnout" sheet;
  - `report`: a printed canvass report saved as CSV.
- **`elections:refreshTurnout`** (also run by the weekly build) reads each election once, checks its wards against the file's own totals, and stores registered voters and ballots per ward.
- **`elections:countTurnout`** (a public query) does the math, in `convex/lib/turnoutMath.ts`.
- **A new Ask tool and card** show the result.

**Tech Stack:** Convex (query, internalAction, internalMutation, convex-test), existing `readWorkbook` (`convex/lib/xlsx.ts`) and `parseCsv` (`convex/lib/stops.ts`), TypeScript, Vitest, Playwright, Zod, Next.js 16.

**Spec:** `docs/superpowers/specs/2026-10-13-turnout-design.md`

## Global Constraints

- **Only public vote totals are stored** (registered voters and ballots per ward).
- **Turnout is computed** as ballots ÷ registered × 100 to one decimal; files' own percentages are never read. A ward with 0 registered shows no turnout (null), never Infinity.
- **Ward cells:** "1", "Ward 1", "01" and 1 become 1; a cell that is "Total" marks a total row.
- **Columns, matched letters-only and lowercase:**
  - ward = "ward" or "wardno";
  - registered = starts with "registeredvoters";
  - ballots = "ballotscast" or "ballotscasttotal".
- **Card text, verbatim:**
  - "Registered voters is the City's count on election day."
  - "Turnout differs by type of election: November general elections draw far more voters than spring or primary ones, so compare like with like."
  - "Ward lines were redrawn in 2022, so a ward number before and after names a different area."
  - "The City's file for <label> couldn't be read."
  - Partial: "The City's <label> file lists only <wards> of the city's <of> wards, so its citywide figure undercounts."
  - Source: "From the City of Milwaukee's election results files (2016–2022), read by the Almanac."
- **Downloads:** only `https://data.milwaukee.gov/` links, 30-second timeout.
- **Git and data rules:**
  - Commit trailer: `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
  - Never stage `.superpowers/` or `clerk-creamcityalmanac.app.zone`.
  - Dev pushes and dev data runs need Tarik's explicit OK; prod data jobs are Tarik's.
- **Local Playwright:** run this app with `npx next dev -p 3100` and `BASE_URL=http://localhost:3100` (port 3000 is another app).

**Planning rulings:**
- **Total checks.** The 2018 August and 2022 August sheets, and the 2020 November report, have no "Total" ward row. Their summary blocks state citywide totals: a "Registered Voters- Total" or "Ballots Cast- Total" label followed by a value, or "01 = REGISTERED VOTERS - TOTAL" / "02 = BALLOTS CAST - TOTAL" lines. Those values serve as the total check.
- **Ranking floor.** Ranking by lowest or highest turnout leaves out wards with fewer than 50 registered voters (a ward of 3 voters would otherwise top or bottom the list), and the card says so. This adds to spec §5.
- **Duplicate wards.** A file that lists the same ward twice fails that election (it would double-count).

## Review Focus

1. **A ward listed twice in a file.** The election fails with a note instead of double-counting. *Pinned in Task 1.*
2. **A ward with 0 registered voters** (the 2022 sheet's last rows). Turnout shows "—" (null), never Infinity or NaN, and the ward is excluded from rankings. *Pinned in Task 2.*
3. **One ward asked across both maps** (ward 12, 2016–2022). The rows come back with the redraw note; a ward number only on the 2022 map (340), asked for 2016–2021, is refused. *Pinned in Task 2.*
4. **The City changes a file's layout** (columns renamed). The election fails naming what wasn't found; earlier rows are kept. *Pinned in Tasks 1 and 3.*
5. **Tiny wards dominating "lowest turnout".** Wards under 50 registered are left out of rankings, and the card says so. *Pinned in Task 2.*

import { quoteId } from "./cityProfile";
import { RID } from "./citySql";
import { parseCsv } from "./stops";

// Milwaukee's per-ward turnout, 2016–2022 (spec 2026-10-13-turnout-design §2, §4). The files differ too much to
// detect, so each election names its catalog family, the file holding its turnout, and how to read it. Pure.
export type ElectionType = "spring" | "primary" | "general";
export type Election = { key: string; label: string; type: ElectionType; familyKey: string; match: RegExp; reader: "table" | "sheet" | "report"; map: "2012" | "2022"; wards: number };
const OLD = { map: "2012" as const, wards: 327 };
export const ELECTIONS: Election[] = [
  { key: "2016-04", label: "April 2016 spring election", type: "spring", familyKey: "city:2016-spring-election-results", match: /voter turnout by ward/i, reader: "table", ...OLD },
  { key: "2016-11", label: "November 2016 general election", type: "general", familyKey: "city:election-2016-11-08", match: /VoterTurnoutbyWardNov82016\.csv/i, reader: "table", ...OLD },
  { key: "2017-02", label: "February 2017 primary", type: "primary", familyKey: "city:election-2017-02-21", match: /VoterTurnoutbyWardFeb212017\.csv/i, reader: "table", ...OLD },
  { key: "2018-04", label: "April 2018 spring election", type: "spring", familyKey: "city:2018-spring-election-results", match: /voter turnout by ward/i, reader: "table", ...OLD },
  { key: "2018-08", label: "August 2018 partisan primary", type: "primary", familyKey: "city:2018-partisan-primary", match: /\.xlsx$/i, reader: "sheet", ...OLD },
  { key: "2018-11", label: "November 2018 general election", type: "general", familyKey: "city:election-2018-11-06", match: /voter turnout/i, reader: "table", ...OLD },
  { key: "2019-04", label: "April 2019 spring election", type: "spring", familyKey: "city:2019-spring-election-results", match: /voter turnout by ward/i, reader: "table", ...OLD },
  { key: "2020-02", label: "February 2020 spring primary", type: "primary", familyKey: "city:2020-spring-primary-election-results", match: /voter turnout by ward/i, reader: "table", ...OLD },
  { key: "2020-04", label: "April 2020 spring election", type: "spring", familyKey: "city:2020-spring-election-results", match: /voter turnout by ward/i, reader: "table", ...OLD },
  { key: "2020-11", label: "November 2020 general election", type: "general", familyKey: "city:2020-general-election", match: /canvassed election results\.csv/i, reader: "report", ...OLD },
  { key: "2021-04", label: "April 2021 spring election", type: "spring", familyKey: "city:2021-spring-election", match: /\.xlsx$/i, reader: "sheet", ...OLD },
  { key: "2022-08", label: "August 2022 partisan primary", type: "primary", familyKey: "city:2022-partisan-primary", match: /2022 partisan primary/i, reader: "sheet", map: "2022", wards: 354 },
];

export type WardRow = { ward: number; registered: number; ballots: number };
export type Read = { ok: true; wards: WardRow[]; total: { registered: number; ballots: number } | null } | { ok: false; why: string };

const letters = (s: unknown) => String(s ?? "").toLowerCase().replace(/[^a-z]/g, "");
const isWard = (h: string) => ["ward", "wardno"].includes(letters(h));
const isRegistered = (h: string) => letters(h).startsWith("registeredvoters");
const isBallots = (h: string) => ["ballotscast", "ballotscasttotal"].includes(letters(h));
export function turnoutColumns(headers: string[]): { ok: true; ward: string; registered: string; ballots: string } | { ok: false; missing: string } {
  const ward = headers.find(isWard), registered = headers.find(isRegistered), ballots = headers.find(isBallots);
  if (!ward) return { ok: false, missing: "ward" };
  if (!registered) return { ok: false, missing: "registered voters" };
  if (!ballots) return { ok: false, missing: "ballots cast" };
  return { ok: true, ward, registered, ballots };
}

// "1", "Ward 1", "01", 1 → 1; "Total" → "total"; anything else (a header, "Ward 1A", blank) → null.
export function wardOf(cell: unknown): number | "total" | null {
  const s = String(cell ?? "").trim();
  if (/^total$/i.test(s)) return "total";
  const m = /^(?:ward\s*)?(\d{1,3})$/i.exec(s);
  return m ? Number(m[1]) : null;
}
const whole = (v: unknown): number | null => {
  const s = String(v ?? "").replace(/[,\s]/g, "");
  return /^\d+(\.0+)?$/.test(s) ? Number.parseInt(s, 10) : null;
};

export function tableSql(resourceId: string, cols: { ward: string; registered: string; ballots: string }): string {
  if (!RID.test(resourceId)) throw new Error("Not a CKAN resource id");
  return `SELECT ${quoteId(cols.ward)}::text AS ward, ${quoteId(cols.registered)}::text AS reg, ${quoteId(cols.ballots)}::text AS bal FROM ${quoteId(resourceId)}`;
}

// Ward rows → wards and the file's total row; a repeated ward or an unreadable number fails the election.
export function readTableRows(rows: { ward: unknown; reg: unknown; bal: unknown }[]): Read {
  const wards: WardRow[] = [];
  let total: { registered: number; ballots: number } | null = null;
  for (const r of rows) {
    const w = wardOf(r.ward);
    if (w === null) continue;
    const registered = whole(r.reg), ballots = whole(r.bal);
    if (w === "total") { if (registered !== null && ballots !== null) total = { registered, ballots }; continue; }
    if (registered === null || ballots === null) return { ok: false, why: `ward ${w} has an unreadable number` };
    if (wards.some((x) => x.ward === w)) return { ok: false, why: `ward ${w} is listed twice` };
    wards.push({ ward: w, registered, ballots });
  }
  return { ok: true, wards, total };
}

// A "General Turnout" sheet: the ward table may sit below a summary block whose "Registered Voters- Total" and
// "Ballots Cast- Total" labels are followed (a cell or two to the right) by the citywide totals.
export function readSheet(rows: string[][]): Read {
  const at = rows.findIndex((r) => turnoutColumns(r).ok);
  if (at < 0) return { ok: false, why: "no ward table with registered voters and ballots cast" };
  const c = turnoutColumns(rows[at]);
  if (!c.ok) return { ok: false, why: `no ${c.missing} column` };
  const idx = (h: string) => rows[at].indexOf(h);
  // A total row may say "Total" in the first column with the ward column blank (2021).
  const read = readTableRows(rows.slice(at + 1).map((r) => ({ ward: /^total$/i.test(String(r[0] ?? "").trim()) ? "Total" : r[idx(c.ward)], reg: r[idx(c.registered)], bal: r[idx(c.ballots)] })));
  if (!read.ok || read.total) return read;
  const stated = (label: string) => {
    for (const r of rows.slice(0, at)) {
      const i = r.findIndex((x) => letters(x) === label);
      if (i >= 0) { const v = r.slice(i + 1).map(whole).find((x) => x !== null); if (v !== undefined) return v; }
    }
    return null;
  };
  const registered = stated("registeredvoterstotal"), ballots = stated("ballotscasttotal");
  return { ...read, total: registered !== null && ballots !== null ? { registered, ballots } : null };
}

// The 2020 November canvass report: its first block of ward lines ("n,City of Milwaukee Ward,n,registered,ballots,
// blank,percent") is turnout; the 25 blocks after it are races, so reading stops at the end of the first block.
// Stated totals are on the "01 = REGISTERED VOTERS - TOTAL" and "02 = BALLOTS CAST - TOTAL" lines.
export function readReport(text: string): Read {
  const rows = parseCsv(text);
  const isWardLine = (r: string[]) => /^city of milwaukee ward$/i.test((r[1] ?? "").trim());
  const start = rows.findIndex(isWardLine);
  const after = start < 0 ? -1 : rows.slice(start).findIndex((r) => !isWardLine(r));
  const block = start < 0 ? [] : rows.slice(start, after < 0 ? undefined : start + after);
  const read = readTableRows(block.map((r) => ({ ward: r[2], reg: r[3], bal: r[4] })));
  if (!read.ok) return read;
  const stated = (re: RegExp) => { const r = rows.find((x) => re.test(x[0] ?? "")); return r ? r.slice(1).map(whole).find((x) => x !== null) ?? null : null; };
  const registered = stated(/^0?1 = REGISTERED VOTERS - TOTAL/i), ballots = stated(/^0?2 = BALLOTS CAST - TOTAL/i);
  return { ...read, total: registered !== null && ballots !== null ? { registered, ballots } : null };
}

// Before storing: the wards must add up to the file's own total (when it states one); fewer wards than the map's
// count marks the election partial.
export function checked(e: Election, r: Read): { ok: true; wards: WardRow[]; partial: boolean; count: number } | { ok: false; why: string } {
  if (!r.ok) return r;
  if (!r.wards.length) return { ok: false, why: "no ward rows" };
  const reg = r.wards.reduce((s, w) => s + w.registered, 0), bal = r.wards.reduce((s, w) => s + w.ballots, 0);
  if (r.total && (r.total.registered !== reg || r.total.ballots !== bal)) {
    return { ok: false, why: `wards add up to ${reg} registered and ${bal} ballots; the file's total says ${r.total.registered} and ${r.total.ballots}` };
  }
  return { ok: true, wards: r.wards, partial: r.wards.length < e.wards, count: r.wards.length };
}

const RESOURCE = /\/resource\/([0-9a-f-]{36})\//;
// The election's file among its family's catalog members: "<member title> <file name>" matches the entry's pattern.
export function sourceFile(e: Election, members: { title: string; files: { name: string; format: string; url: string }[] }[]): { url: string; resourceId: string | null } | null {
  for (const m of members) for (const f of m.files) {

import type { ElectionType } from "./turnout";

// countTurnout's math (spec 2026-10-13-turnout-design §5): code computes every figure; the AI writes none.
export type StoredElection = { election: string; label: string; type: ElectionType; map: "2012" | "2022"; wards: number; of: number; partial: boolean; status: "read" | "failed" };
export type TurnoutArgs = { type?: ElectionType | "all"; from?: number; to?: number; ward?: number; groupBy?: "election" | "ward"; order?: "lowest" | "highest" };
export type TurnoutRow = { label: string; type: ElectionType | null; registered: number; ballots: number; turnout: number | null; partial?: boolean };
export type TurnoutResult =
  | { status: "ok"; title: string; groupBy: "election" | "ward"; rows: TurnoutRow[]; notes: string[]; source: string }
  | { status: "refused"; reason: string };

export const RANK_FLOOR = 50;
const RANK_N = 10;
const REG = "Registered voters is the City's count on election day.";
const MIX = "Turnout differs by type of election: November general elections draw far more voters than spring or primary ones, so compare like with like.";
const REDRAW = "Ward lines were redrawn in 2022, so a ward number before and after names a different area.";
const SOURCE = "From the City of Milwaukee's election results files (2016–2022), read by the Almanac.";
const YEARS = "Turnout is available for elections from 2016 to 2022.";
const pct = (b: number, r: number) => (r > 0 ? Math.round((1000 * b) / r) / 10 : null);
const yearOf = (election: string) => Number(election.slice(0, 4));

type WardIn = { election: string; ward: number; registered: number; ballots: number };
export function summarize(rows: WardIn[], elections: StoredElection[], a: TurnoutArgs): TurnoutResult {
  if (!rows.length) return { status: "refused", reason: "Turnout hasn't been built yet." };
  const from = a.from ?? 2016, to = a.to ?? 2022;
  if (!Number.isInteger(from) || !Number.isInteger(to) || from > to || to < 2016 || from > 2022) return { status: "refused", reason: YEARS };
  const type = a.type ?? "all";
  const inRange = (e: StoredElection) => yearOf(e.election) >= from && yearOf(e.election) <= to && (type === "all" || e.type === type);
  const read = elections.filter((e) => e.status === "read" && inRange(e)).sort((x, y) => x.election.localeCompare(y.election));
  const failed = elections.filter((e) => e.status === "failed" && inRange(e));
  const groupBy = a.groupBy ?? "election";
  if (a.order && groupBy !== "ward") return { status: "refused", reason: "Lowest or highest wards need groupBy ward and one election." };
  if (groupBy === "ward" && read.length !== 1) return { status: "refused", reason: "Ward lists are for one election at a time: pick one election, or ask for one ward across elections." };
  if (!read.length) return { status: "refused", reason: failed.length ? failed.map((e) => `The City's file for ${e.label} couldn't be read.`).join(" ") : YEARS };

  const byElection = new Map<string, WardIn[]>();
  for (const r of rows) byElection.set(r.election, [...(byElection.get(r.election) ?? []), r]);
  if (a.ward !== undefined && !read.some((e) => (byElection.get(e.election) ?? []).some((w) => w.ward === a.ward))) {
    const max = Math.max(...read.map((e) => e.of));
    return { status: "refused", reason: `Ward ${a.ward} isn't on the ward map of the elections asked (${from}–${to}: wards 1–${max}).` };
  }

  const notes = [REG];
  let out: TurnoutRow[];
  if (groupBy === "ward") {
    const e = read[0];
    const wards = byElection.get(e.election) ?? [];
    const ranked = wards.filter((w) => w.registered >= RANK_FLOOR).map((w) => ({ label: `Ward ${w.ward}`, type: null, registered: w.registered, ballots: w.ballots, turnout: pct(w.ballots, w.registered) }));
    ranked.sort((x, y) => (a.order === "highest" ? (y.turnout ?? 0) - (x.turnout ?? 0) : (x.turnout ?? 0) - (y.turnout ?? 0)));
    out = a.order ? ranked.slice(0, RANK_N) : ranked;
    if (ranked.length < wards.length) notes.push(`Wards with fewer than ${RANK_FLOOR} registered voters are left out of the ranking.`);
  } else {
    // One ward: only the elections whose map has it (ward 340 exists from 2022 only).
    const shown = a.ward === undefined ? read : read.filter((e) => (byElection.get(e.election) ?? []).some((w) => w.ward === a.ward));
    out = shown.map((e) => {
      const ws = (byElection.get(e.election) ?? []).filter((w) => a.ward === undefined || w.ward === a.ward);
      const registered = ws.reduce((s, w) => s + w.registered, 0), ballots = ws.reduce((s, w) => s + w.ballots, 0);
      const partial = e.partial && a.ward === undefined;
      return { label: partial ? `${e.label} (wards 1–${e.wards} of ${e.of} only)` : e.label, type: e.type, registered, ballots, turnout: pct(ballots, registered), ...(partial ? { partial: true } : {}) };
    });
    if (new Set(shown.map((e) => e.type)).size > 1) notes.push(MIX);
    if (a.ward === undefined) for (const e of shown.filter((x) => x.partial)) notes.push(`The City's ${e.label} file lists only ${e.wards} of the city's ${e.of} wards, so its citywide figure undercounts.`);
    if (a.ward !== undefined && new Set(shown.map((e) => e.map)).size > 1) notes.push(REDRAW);
  }
  notes.push(...failed.map((e) => `The City's file for ${e.label} couldn't be read.`));
  const types = type === "all" ? "all elections" : `${type} elections`;
  const years = read.length === 1 ? read[0].label : `${yearOf(read[0].election)}–${yearOf(read[read.length - 1].election)}`;
  return { status: "ok", title: ["Milwaukee voter turnout", types, years, ...(a.ward !== undefined ? [`ward ${a.ward}`] : [])].join(" · "), groupBy, rows: out, notes, source: SOURCE };
}

export const replaceElection = internalMutation({
  args: { election: v.string(), modified: v.string(), wards: v.array(v.object({ ward: v.number(), registered: v.number(), ballots: v.number() })), partial: v.boolean() },
  handler: async (ctx, { election, modified, wards, partial }) => {
    const e = ELECTIONS.find((x) => x.key === election)!;
    for (const old of await ctx.db.query("turnout").withIndex("by_election", (q) => q.eq("election", election)).collect()) await ctx.db.delete(old._id);
    for (const w of wards) await ctx.db.insert("turnout", { election, ...w });
    const row = { ...meta(e), wards: wards.length, partial, modified, status: "read" as const };
    const old = await ctx.db.query("elections").withIndex("by_election", (q) => q.eq("election", election)).first();
    if (old) await ctx.db.replace(old._id, row); else await ctx.db.insert("elections", row);

    if (old) await ctx.db.replace(old._id, row); else await ctx.db.insert("elections", row);

async function download(url: string): Promise<Response> {
  if (!url.startsWith("https://data.milwaukee.gov/")) throw new Error("not a City link");
  const res = await fetchWithTimeout(url, {}, DOWNLOAD_TIMEOUT_MS);
  if (!res.ok) throw new Error(`download failed: ${res.status}`);
  return res;
}

async function readElection(e: Election, src: { url: string; resourceId: string | null }): Promise<Read> {
  if (e.reader === "table") {
    if (!src.resourceId) return { ok: false, why: "the file's link has no id" };
    const c = turnoutColumns((await datastoreFields(src.resourceId)).map((f) => f.id));
    if (!c.ok) return { ok: false, why: `no ${c.missing} column` };
    return readTableRows(await datastoreSql<{ ward: unknown; reg: unknown; bal: unknown }>(tableSql(src.resourceId, c)));
  }
  const res = await download(src.url);
  if (e.reader === "report") return readReport(await res.text());
  const sheet = readWorkbook(new Uint8Array(await res.arrayBuffer())).find((s) => s.name.trim().toLowerCase() === "general turnout");
  return sheet ? readSheet(sheet.rows) : { ok: false, why: "no General Turnout sheet" };
}

// Weekly (build.finish) or alone: `npx convex run elections:refreshTurnout`. Notes, never throws. An election is read
// once and skipped while its catalog entry is unchanged; a failure keeps earlier rows and is retried next time.
export const refreshTurnout = internalAction({
  args: {},
  handler: async (ctx): Promise<string[]> => {
    const notes: string[] = [];
    const done = new Map((await ctx.runQuery(internal.elections.electionStatus, {})).map((s) => [s.election, s]));
    for (const s of await ctx.runQuery(internal.elections.electionSources, {})) {
      const e = ELECTIONS.find((x) => x.key === s.key)!;
      const prev = done.get(e.key);
      if (prev?.status === "read" && prev.modified === s.modified) continue;
      const src = sourceFile(e, s.members);
      if (!src) { notes.push(`Turnout ${e.label}: no turnout file in the catalog`); continue; }
      try {
        const c = checked(e, await readElection(e, src));
        if (!c.ok) throw new Error(c.why);
        await ctx.runMutation(internal.elections.replaceElection, { election: e.key, modified: s.modified, wards: c.wards, partial: c.partial });
      } catch (err) {
        notes.push(`Turnout ${e.label}: ${message(err)}; kept any earlier rows`);
        await ctx.runMutation(internal.elections.markElectionFailed, { election: e.key, modified: s.modified, note: message(err) });
      }
    }
    return notes;
  },
});

  },

import type { TurnoutAnswer } from "@/lib/ask/tools";
import type { FollowUp } from "@/ui/components/FollowUps";
import { exported, safeName, type CardExport, type Ctx } from "./cardExport";

// The turnout card's words and export (spec 2026-10-13-turnout-design §6), from the stored totals.
export type TurnoutOk = Extract<TurnoutAnswer, { status: "ok" }>;
export const turnoutText = (x: number | null) => (x === null ? "—" : `${x}%`);
const firstHead = (r: TurnoutOk) => (r.groupBy === "ward" ? "Ward" : "Election");

export function turnoutExport(r: TurnoutOk, ctx: Ctx): CardExport {
  return {
    title: r.title,
    lines: [],
    csv: { head: [firstHead(r), "Registered voters", "Ballots cast", "Turnout (%)"], rows: r.rows.map((x) => [x.label, x.registered, x.ballots, x.turnout]) },
    text: { head: [firstHead(r), "Registered voters", "Ballots cast", "Turnout"], rows: r.rows.map((x) => [x.label, x.registered.toLocaleString("en-US"), x.ballots.toLocaleString("en-US"), turnoutText(x.turnout)]) },
    notes: [...r.notes, r.source, exported(ctx)],
    filename: safeName(["turnout", r.groupBy]),
  };
}

type Args = { type?: string; from?: number; to?: number; ward?: number; groupBy?: string };
export function turnoutFollowUps(a: Args, r: TurnoutOk): FollowUp[] {
  const out: FollowUp[] = [];
  const types = new Set(r.rows.map((x) => x.type).filter(Boolean));
  if (r.groupBy === "election" && types.size > 1) out.push({ label: "ONLY NOVEMBER ELECTIONS", question: `How did turnout change across November general elections${a.ward !== undefined ? ` in ward ${a.ward}` : ""}?` });
  const newest = r.groupBy === "election" ? r.rows.at(-1)?.label.replace(/ \(wards.*\)$/, "") : undefined;
  if (newest && a.ward === undefined) out.push({ label: "LOWEST-TURNOUT WARDS", question: `Which wards had the lowest turnout in the ${newest}?` });
  if (r.groupBy === "ward" && r.rows[0]) out.push({ label: "THIS WARD OVER TIME", question: `How has turnout changed in ${r.rows[0].label} across elections?` });
  return out.slice(0, 3);
}
