# How Long Things Have Been Open (L2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ask answers "how long have today's vacant buildings been vacant?" and "how long have open complaints been waiting?" with "age" entries in the existing list of measurable pairs.

**Architecture:**
- `SpanPair` becomes a union of `"between"` (today's pairs) and `"age"` (start date → as-of date, optionally only rows whose close column is empty).
- `buildSpan` gets an age branch that measures `asOf − start`.
- `timeSpan` picks the as-of date: today, or the file's `latestModified`.
- The card's wording switches on the kind.
- Same tool, same card, same export.

**Tech Stack:** Convex (action, convex-test), City CKAN `datastore_search_sql`, CopilotKit `useRenderTool`, Vitest, Playwright, graded real-AI script.

**Spec:** `docs/superpowers/specs/2026-10-14-open-age-design.md`

## Global Constraints

- **The two entries (spec §4):**
  - `vacant-age`: `DATEOPENED`, no `openWhen`, asOf `"today"`, name "time vacant so far", things "buildings", toWhat "on the vacant list".
  - `complaint-open-age`: `DateReported`, openWhen `Date Closed`, asOf `"file"`, name "time open so far", things "open complaints", toWhat "open".
- **As-of notes, verbatim (spec §4):**
  - **Vacant:** "As of {date}: buildings still on the City's vacant-building list. The date is when the City registered the building as vacant, not when it emptied. Buildings taken off the list aren't counted."
  - **Complaints:** "As of {date}, when the City last updated this file. Complaints with no close date then are counted; some may have closed since."
- **Summary (spec §7):**
  - "Half of the {things} have been {toWhat} {median} or more; 1 in 10 for {p90} or more."
  - With a split: "Overall, half of the {things} have been {toWhat} {median} or more. Longest: {label} ({median}); shortest: {label} ({median})."
- **Durations for ages:** one year or more prints as years with one decimal ("2.1 years"); under a year prints in today's day format.
- **Age table columns:** group, Cases, Median, Longest 1 in 10. No "Still open" column.
- **The future-dated note:** "{n} records dated after the as-of date were left out."
- **Between pairs behave exactly as before:** same SQL, same card, same export.
- **Never return rows, addresses or single buildings.** Totals per group only.

```ts
  // An age (L2) runs to the end of its as-of day; a later "from" date is a record dated after it, never a negative age.
  const age = pair.kind === "age";
  const cutoff = age ? `${lit(addDays(asOf ?? today, 1))}::timestamp` : "";
  if (age && pair.openWhen) inner.push(`NOT ${present(pair.openWhen)}`);
  const innerSql = (grouped: boolean) =>
    `SELECT ${readDate(pair.from)} AS f, ${pair.kind === "between" ? `${readDate(pair.to)} AS t, ` : ""}${present(pair.from)} AS hf${pair.kind === "between" ? `, ${present(pair.to)} AS ht` : ""}${grouped && g ? `, ${g} AS g` : ""} FROM ${table}${inner.length ? ` WHERE ${inner.join(" AND ")}` : ""}`;
  const d = age ? `CASE WHEN f < ${cutoff} THEN date_part('epoch', ${cutoff} - f) / 86400 END` : `CASE WHEN t >= f THEN date_part('epoch', t - f) / ${PER[pair.unit]} END`;
  const measures = (age
    ? [
        `SUM(CASE WHEN f < ${cutoff} THEN 1 ELSE 0 END) AS cases`,
        `percentile_cont(0.5) WITHIN GROUP (ORDER BY ${d}) AS median`,
        `percentile_cont(0.9) WITHIN GROUP (ORDER BY ${d}) AS p90`,
        "0 AS open",
        "SUM(CASE WHEN hf AND f IS NULL THEN 1 ELSE 0 END) AS unreadable",
        `SUM(CASE WHEN f >= ${cutoff} THEN 1 ELSE 0 END) AS backwards`,
      ]
    : [
        "SUM(CASE WHEN t >= f THEN 1 ELSE 0 END) AS cases",
        `percentile_cont(0.5) WITHIN GROUP (ORDER BY ${d}) AS median`,
        `percentile_cont(0.9) WITHIN GROUP (ORDER BY ${d}) AS p90`,
        "SUM(CASE WHEN hf AND NOT ht THEN 1 ELSE 0 END) AS open",
        "SUM(CASE WHEN (hf AND f IS NULL) OR (ht AND t IS NULL) THEN 1 ELSE 0 END) AS unreadable",
        "SUM(CASE WHEN t < f THEN 1 ELSE 0 END) AS backwards",
      ]).join(", ");
```

export function asOfDay(pair: SpanPair, modified: string | undefined, now: number): string | null {
