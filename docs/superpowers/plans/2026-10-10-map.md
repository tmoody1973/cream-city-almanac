# The Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One map component draws City neighborhood boundaries, incident patterns as banded quarter-mile areas (never dots), and the City's ArcGIS map layers — on Ask's count card and in a new WHERE section on dataset sheets.

**Architecture:** Incident cells are built on the server from the same logic as `countRecords` (neighborhood: points already tested against the boundary; citywide: a City SQL grid query) and sent as `(i, j, band)` — never coordinates. A public `mapCells` action serves sheet maps behind a 10-minute cache and a site-wide limit. The browser draws with MapLibre over OpenFreeMap tiles and fetches City map layers directly (CORS `*`) for the visible area only.

**Tech Stack:** Convex (actions, queries, convex-test), `@convex-dev/rate-limiter`, Next.js App Router (client components, `next/dynamic`), MapLibre GL JS `6.11.2`, OpenFreeMap styles, CopilotKit v2 render hooks, Vitest, Playwright, axe.

**Spec:** `docs/superpowers/specs/2026-10-10-map-design.md`

## Global Constraints

- Read `convex/_generated/ai/guidelines.md` before writing Convex code. Use `npx ctx7@latest` for MapLibre 6 API questions (library "MapLibre GL JS").
- New dependency: exactly `maplibre-gl@6.11.2` (pinned, no caret). No other new packages.
- Basemap styles: `https://tiles.openfreemap.org/styles/positron` (day), `https://tiles.openfreemap.org/styles/dark` (night). Night = `<html data-theme="dark">`, or no `data-theme` and `prefers-color-scheme: dark`.
- Grid: `dLat = 0.0036`, `dLon = 0.0049` (≈ a quarter mile), `i = floor(lat / dLat)`, `j = floor(lon / dLon)`.
- Bands: 1 = 1–4, 2 = 5–19, 3 = 20 or more. Exact counts (`n`) only for cells with 5 or more.
- Never send coordinates or addresses to the browser; never draw individual incidents.
- Legend words exactly: "1–4 in an area", "5–19", "20 or more", "<Name> (City boundary)". Note line exactly: "Areas are quarter-mile squares, never addresses."
- Summary sentence: `"{total} records in {areas} quarter-mile areas; {fivePlus} had 5 or more (busiest: {busiest})."` plus `" {count − total} without a location aren't on the map."` when the count is larger.
- Bands render by pattern: band 1 diagonal hatching in full ink, band 2 cross-hatching, band 3 solid ink at 0.7 opacity. Boundary: `--pencil` color, 3px.
- Map element: `role="img"`, `aria-label` = the summary sentence; legend is a `<ul>`; cooperative gestures on (one finger scrolls the page).
- One live map per Ask conversation: the newest count card; older cards show a "Show map" button.
- `mapCells` cache: 10 minutes; site-wide limit `mapCity` = token bucket, rate 60 per minute, capacity 20; busy text: "The map is busy; try again in a minute."
- City layers: browser query per view envelope, `outSR=4326`, `f=geojson`; `exceededTransferLimit` → "Zoom in to see {layer name}."; failure → "This City map layer isn't responding."; label up to 6 non-system fields.
- City SQL constructs: only those already in `convex/lib/citySql.ts` plus `floor()` and `GROUP BY i, j` (verified live 2026-10-10). Add every new SQL shape to `scripts/city-sql-smoke.ts` and run it.
- Commit trailers name the implementing model. No production deploys by Claude.
- Tests: `npx vitest run --maxWorkers=2`; e2e against `npx next dev -p 3200` with `set -a; . ./.env.local; set +a; BASE_URL=http://localhost:3200 npx playwright test …`.

## Review Focus

1. A citywide count includes records with no location, which the map can't place: the map summary must show fewer records than the count and say how many aren't on the map, never imply they match — pinned in Task 3.
2. A sheet map for a long period citywide must still draw (grid query, no 32,000-row "too broad"); only neighborhood views can be too broad — pinned in Task 3.
3. Changing sheet filters quickly must not leave an older, slower answer on screen after a newer one — pinned in Task 7 (request sequence guard; the e2e changes two filters back to back and asserts the final answer matches the last).
4. Switching between day and night editions while a map is open must restyle it without losing the cells and boundary — pinned in Task 9 Step 1a (CityMap redraws after `setStyle`, Task 5).
5. Opening a second Ask count card's map must close the first (one live map), and a brand-new count must become the live one — pinned in Task 6 (unit test of `lastCountId`; e2e asserts exactly one map canvas on the page).

```ts
// convex/lib/cityMap.ts
// Where incidents happened, as quarter-mile areas: a fixed grid, three bands, exact counts only from 5 up. The map
// never gets a coordinate or an address; NIBRS publishes exact addresses, so these squares are the finest it shows.
export const CELL = { dLat: 0.0036, dLon: 0.0049 } as const;

export const cellOf = (lat: number, lon: number) => `${Math.floor(lat / CELL.dLat)},${Math.floor(lon / CELL.dLon)}`;
export const band = (n: number): 1 | 2 | 3 => (n < 5 ? 1 : n < 20 ? 2 : 3);

export type MapCell = { i: number; j: number; band: 1 | 2 | 3; n?: number };
export type MapData = {
  size: typeof CELL;
  cells: MapCell[];
  summary: { total: number; areas: number; fivePlus: number; busiest: number };
  area: string | null;
};

export function toMapData(counts: Map<string, number>, area: string | null): MapData {
  const cells: MapCell[] = [];
  let total = 0, fivePlus = 0, busiest = 0;
  for (const [key, n] of counts) {
    if (n <= 0) continue;
    const [i, j] = key.split(",").map(Number);
    cells.push(n >= 5 ? { i, j, band: band(n), n } : { i, j, band: 1 });
    total += n;
    if (n >= 5) fivePlus++;
    busiest = Math.max(busiest, n);
  }
  return { size: CELL, cells, summary: { total, areas: cells.length, fivePlus, busiest }, area };
}
```

```ts
import { runCount, type CountResult } from "./city";
import { chicagoDay } from "./lib/ask";
import { hashInputs } from "./lib/hash";
import { nameKey } from "./lib/neighborhoodNames";
import { rateLimiter } from "./limits";

const TTL_MS = 10 * 60_000;
const vFilter = v.object({ column: v.string(), values: v.array(v.string()) });

// The sheet's map: anyone can use it. Identical requests (same day) come from the cache; new ones spend the
// site-wide City budget. Same logic, refusals and privacy as Ask's count — cells only, never coordinates.
export const mapCells = action({
  args: { code: v.string(), from: v.optional(v.string()), to: v.optional(v.string()), filters: v.optional(v.array(vFilter)), neighborhood: v.optional(v.string()) },
  handler: async (ctx, args): Promise<CountResult> => {
    const input = {
      code: args.code.trim().toUpperCase(),
      from: args.from || undefined,
      to: args.to || undefined,
      filters: (args.filters ?? []).map((f) => ({ column: f.column, values: [...f.values].sort() })).sort((a, b) => a.column.localeCompare(b.column)),
      neighborhood: args.neighborhood?.trim() ? nameKey(args.neighborhood) : undefined,
    };
    const key = await hashInputs({ ...input, day: chicagoDay(Date.now()) });
    const hit: string | null = await ctx.runQuery(internal.map.cached, { key, now: Date.now() });
    if (hit) return JSON.parse(hit) as CountResult;
    if (!(await rateLimiter.limit(ctx, "mapCity")).ok) return { status: "busy" as const };
    const result = await runCount(ctx, { ...input, neighborhood: args.neighborhood });
    if (result.status !== "unavailable" && result.status !== "busy") {
      await ctx.runMutation(internal.map.remember, { key, result: JSON.stringify(result), expiresAt: Date.now() + TTL_MS });
    }
    return result;
  },
});

export const cached = internalQuery({
  args: { key: v.string(), now: v.number() },
  handler: async (ctx, { key, now }) => {
    const row = await ctx.db.query("mapCache").withIndex("by_key", (q) => q.eq("key", key)).first();
    return row && row.expiresAt > now ? row.result : null;
  },
});

// Stores one answer and drops a few expired ones, so the table never grows past a day's worth of distinct maps.
export const remember = internalMutation({
  args: { key: v.string(), result: v.string(), expiresAt: v.number() },
  handler: async (ctx, row) => {
    const old = await ctx.db.query("mapCache").withIndex("by_key", (q) => q.eq("key", row.key)).first();
    if (old) await ctx.db.replace(old._id, row);
    else await ctx.db.insert("mapCache", row);
    for (const stale of await ctx.db.query("mapCache").filter((q) => q.lt(q.field("expiresAt"), Date.now())).take(20)) await ctx.db.delete(stale._id);
  },
});
```

```ts
// ui/lib/mapCells.ts
import type { MapData } from "@/convex/lib/cityMap";

const r6 = (x: number) => Math.round(x * 1e6) / 1e6;

export function cellsToGeoJSON(d: MapData): GeoJSON.FeatureCollection<GeoJSON.Polygon, { band: number; label: string }> {
  return {
    type: "FeatureCollection",
    features: d.cells.map((c) => {
      const [y0, x0] = [r6(c.i * d.size.dLat), r6(c.j * d.size.dLon)];
      const [y1, x1] = [r6(y0 + d.size.dLat), r6(x0 + d.size.dLon)];
      return { type: "Feature", properties: { band: c.band, label: c.n ? String(c.n) : "1–4" }, geometry: { type: "Polygon", coordinates: [[[x0, y0], [x1, y0], [x1, y1], [x0, y1], [x0, y0]]] } };
    }),
  };
}

export function summarySentence(d: MapData, count: number): string {
  const s = d.summary;
  const base = `${s.total.toLocaleString("en-US")} records in ${s.areas} quarter-mile areas; ${s.fivePlus} had 5 or more (busiest: ${s.busiest}).`;
  const off = count - s.total;
  return off > 0 ? `${base} ${off.toLocaleString("en-US")} without a location aren't on the map.` : base;
}
```

```ts
function subscribe(onChange: () => void) {
  const media = window.matchMedia("(prefers-color-scheme: dark)");

  obs.observe(document.documentElement, { attributes: true, attributeFilter: ["data-theme"] });
```

```tsx
// Hatching drawn in the edition's ink: 1–4 diagonal, 5–19 crossed. Patterns read without relying on faint shades.
function pattern(color: string, crossed: boolean, size: number): ImageData {
  const c = document.createElement("canvas");
  c.width = c.height = size;
  const x = c.getContext("2d")!;
  x.strokeStyle = color; x.lineWidth = 2; x.beginPath();
  x.moveTo(0, size); x.lineTo(size, 0); x.moveTo(-2, 2); x.lineTo(2, -2); x.moveTo(size - 2, size + 2); x.lineTo(size + 2, size - 2);
  if (crossed) { x.moveTo(0, 0); x.lineTo(size, size); x.moveTo(-2, size - 2); x.lineTo(2, size + 2); x.moveTo(size - 2, -2); x.lineTo(size + 2, 2); }
  x.stroke();
  return x.getImageData(0, 0, size, size);
}
```

```ts
// The City's ArcGIS map layers, fetched by the browser (the City allows it) for the visible area only. These are
// places — routes, zones, districts — drawn as published. The City answers at most 2,000 shapes per request.
type View = [[number, number], [number, number]];
const SYSTEM = /^(objectid|fid|globalid|shape.*)$/i;

export function layerQueryUrl(layerUrl: string, [[w, s], [e, n]]: View): string {
  const u = new URL(`${layerUrl.replace(/\/+$/, "")}/query`);
  for (const [k, v] of Object.entries({ where: "1=1", geometry: `${w},${s},${e},${n}`, geometryType: "esriGeometryEnvelope", inSR: "4326", outSR: "4326", spatialRel: "esriSpatialRelIntersects", outFields: "*", f: "geojson" })) u.searchParams.set(k, v);
  return u.toString();
}

export const labelFields = (props: Record<string, unknown>): [string, string][] =>
  Object.entries(props).filter(([k, v]) => !SYSTEM.test(k) && v !== null && v !== "").slice(0, 6).map(([k, v]) => [k, String(v)]);

export async function fetchLayer(url: string, view: View): Promise<{ status: "ok"; data: GeoJSON.FeatureCollection } | { status: "too-many" } | { status: "down" }> {
  try {
    const res = await fetch(layerQueryUrl(url, view));
    if (!res.ok) return { status: "down" };
    const body = (await res.json()) as GeoJSON.FeatureCollection & { exceededTransferLimit?: boolean; error?: unknown };
    if (body.error || !Array.isArray(body.features)) return { status: "down" };
    if (body.exceededTransferLimit) return { status: "too-many" };
    return { status: "ok", data: { type: "FeatureCollection", features: body.features } };
  } catch {
    return { status: "down" };
  }
}
```

```markdown
**Decision:** Maps show incidents as shaded quarter-mile squares in three bands (1–4, 5–19, 20 or more), never as dots at addresses, over OpenFreeMap streets; anyone can use the sheet map.

**Why this came up:** The City publishes crime records with exact street addresses. A map of dots would point at specific homes, sometimes a victim's. But a count is easier to trust when you can see where it falls.
```
